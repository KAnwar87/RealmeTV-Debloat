# Package snapshots

Taken over ADB on 25 Oct 2026 (Realme TV, Changhong `AI PONT` / `ikebukuro`, Android TV 11).

| File | Contents |
|---|---|
| `system-packages.txt` | Factory system packages, before any change |
| `already-disabled.txt` | Packages disabled from the factory |
| `home-apps.txt` | Apps that claimed the Home screen before changes |
| `disabled-after-debloat.txt` | Disabled packages after both batches (if taken) |

The lists of user-installed apps (`user-packages.txt`, `user-apps-after.txt`) are personal, so they stay local and are ignored by git.
